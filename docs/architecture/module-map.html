Email Agent Module Map

Human review map for the module/submodule architecture. Agent context starts in module-index.md, then local cards.

Core Runtime

actionsAction definitions, registry, runner, user action files, and Gmail operation mapping.
agentsProvider executors and fallback routing for Claude, Codex, Gemini, OpenRouter, and direct API.
gmailAuth, accounts, fetch, sync, and write operations.
dbLanceDB schemas, table helpers, filters, and embeddings.
analysisSummaries, digests, clusters, and citations.
config/sharedSettings, defaults, paths, prompts, vector constants.

Interfaces

web app/APINext App Router pages and thin API adapters over core.
web modules/apiRequest validation contracts shared by route handlers.
web UIActions, mail, shared chrome, primitives, hooks, and stores.
cliCommander commands that call the core barrel export only.

Primary Flows

  • Fetch: CLI/web -> Gmail sync -> embeddings -> LanceDB.
  • Run action: CLI/web -> actions runner -> agent router -> optional Gmail writes -> action results table.
  • Generate action: web chat -> skill docs -> agent router -> user action source persisted under ~/.email-agent/actions.
  • Analyze: web route -> analysis module -> agent router or DB clusters.
